Check what you remember from this chapter. Answer each flashcard in your head, then turn it over and choose Got it or Missed it. Cards you do not know yet come back sooner. The quiz mixes the questions from this chapter's pages and asks 10 at a time.

[Chapter 14](../structuring-programs/overview.md) starts from the tag `ch13`, a name saved on one commit, with its code reorganized into modules and into classes, blueprints for a kind of thing in a program. It teaches you to read the structured code that agents write and that SDKs hold. An SDK is a package a company publishes so programs can use its service.

**Further reading.** Imad Muratspahic, [*Learn to Code in the AI Era*](https://books.google.com/books/about/Learn_to_Code_in_the_AI_Era.html?id=iUYXEgAAQBAJ), 2026. It is a short guide for computer science students and new developers on building real skill without ignoring AI tools.
